# Chroma Service (Deprecated for this repo)

This repository now uses Chroma Cloud from the backend and does not require a self-hosted Chroma service.

Use backend environment variables instead:

- `CHROMA_API_KEY`
- `CHROMA_TENANT`
- `CHROMA_DATABASE`
- `CHROMA_CLOUD_HOST` (default `api.trychroma.com`)
- `CHROMA_CLOUD_PORT` (default `8000`)
- `CHROMA_CLOUD_SSL` (default `true`)
